01 · Foundations · 5 minutes

Meet your assistant. Keep your judgment.

You will learn: what Copilot helps with, where to begin, and what it cannot decide for you.

Copilot Chat

A conversation: ask questions, brainstorm, summarize supplied material, and draft content. You give instructions in everyday language. A message you send is a prompt.

Copilot inside an app

Help in the context of a document, workbook, presentation, email, or meeting. Some experiences suggest content; others can edit the open artifact. Check the mode before asking for changes.

Do this

  1. Open the Microsoft 365 Copilot app and sign in with your work account. If your organization provides a different approved entry point, use that.
  2. Open Chat and find the message box. Check the signed-in account. If access is blocked, use your organization's support process rather than switching to a personal account with work data.
  3. Start a new conversation. Notice the new-chat control, the message history, and any source or file-attachment controls available to you. Labels vary; you do not need every control to start.
  4. Keep these guides in a second tab. You will copy a prompt from the next lesson into Chat, not type private information into this website.

What good looks like

You can open an approved work conversation and explain that Copilot generates a useful draft, not a guaranteed fact or automatic approval.

Know the boundary: it can misunderstand, omit details, and confidently invent information. It cannot infer every unstated business rule. A draft task list is not a set of assigned tasks; a draft email is not a sent email.

If you are stuck: confirm you are signed in with the right work account and ask your organization's support team about the app entry point. There is no separate sign-in to this guide.

02 · Foundations · 5 minutes

Get your first useful answer.

You will learn: to turn a small set of notes into a usable draft. Need: Copilot Chat; no file or work-data search required.

Do this

  1. Start a new chat. Copy the complete prompt below, including the fictional notes.
  2. Paste it into Copilot's message box and send it. Read the whole answer before judging it.
  3. Compare its claims with the notes. A useful answer can be short; it does not need to sound impressive.
Try this · summarize
Write a short status update for the organizer of this fictional employee welcome session.
Use only the notes below. Give me three bullets: confirmed facts, next action, and open decisions.
Do not invent dates, approvals, or completed work.

Notes:
- A 30-minute welcome session is planned for 12 new colleagues on 14 October; the year is not specified.
- Alex coordinates the session.
- Priya will draft the handout by 8 October.
- The budget limit is 600 USD; approved spending is not specified.
- No room is booked.
- Online versus in-person delivery is still undecided.

Check the result

The session is planned, not fully confirmed. The room is not booked, 600 USD is a limit rather than approved spending, and the format is undecided. The answer must not supply a year, claim Priya finished, or say invitations were sent.

Try one follow-up: "Make it two sentences, keeping the uncertainty about the room and delivery format." Send it in the same chat so Copilot can use the previous exchange.

If it invents a fact: point out the exact error and ask for a correction using only the notes. Recheck the correction; do not assume the second answer is right.

03 · Foundations · 7 minutes

Give the task a clear brief.

You will learn: a reusable prompting pattern and how to improve a response without starting over.

Goal

What should Copilot do? Draft, explain, compare, summarize, analyze, or brainstorm.

Context

Who is this for, and why? State the audience, situation, and decision you need to make.

Source

Which notes, file, messages, or public sources should it use? Name or attach material it can actually access.

Expectations

Specify format, length, tone, boundaries, and how to handle missing information.

Compare "Help with an event" with the prompt below. Not every request needs all four elements, and there is no magic order.

  1. Use the same fictional event from guide 02 or start fresh with the complete prompt below.
  2. Ask for a bounded output. Then change one thing at a time: length, audience, format, or depth.
  3. Keep refining the same task in one conversation. Start a new chat for a different project to avoid carrying over irrelevant assumptions.
Try this · plan
Draft a proposed agenda for a fictional 30-minute welcome session for 12 new colleagues.
The goal is to help them meet one another and know where to ask for help.
The only confirmed inputs are the duration and audience size. The delivery format is not decided.
Return a table with activity, minutes, and purpose. The minutes must total 30.
Keep activities usable online or in person. Label the agenda as a proposal, not an approved plan.
Then refine in the same chat
Revise the proposal so introductions take no more than 8 minutes.
Keep the whole agenda at 30 minutes. Explain what you changed in one sentence.
Separate any new assumptions from the agenda.

Check the result

Add the minutes yourself: they must total 30. Are introductions 8 minutes or less? Does the answer preserve the undecided format? Ask for changes if it does not.

Reuse the pattern: "Do [task] for [audience/purpose], using [source]. Return [format/length]. Do not [boundary]. If something is missing, [ask or flag it]." Replace every bracket before sending.

04 · Foundations · 7 minutes

Give it the right information.

You will learn: the difference between public-web research, supplied content, and organizational context. Grounding means supplying or retrieving information to base an answer on; it reduces guesswork, not the need to review.

Public web

Useful for public information and research where enabled. Ask for source links and check their dates. A web answer is not an answer about your internal project.

Your work and supplied files

Use work context to ask about information you have permission to access, or explicitly attach a file or provide notes. Inside an app, identify the document or conversation you mean. Naming a file is not proof that Copilot read it.

Do this

  1. Download the fictional Northstar research summary. This is the same practice document used in the original lab.
  2. In a new work chat, use the available attachment or content-reference control to select that document. If your experience references cloud files, save the practice copy to your work OneDrive or SharePoint first. Confirm the correct file is shown.
  3. Send the prompt below. Open the original document beside the response, not only the generated citations.
  4. For a separate public-web exercise, start a new chat and ask: "Find Microsoft's current guidance on writing Copilot prompts. Link the official source and separate its advice from your suggestions." If web access is unavailable, read the official source linked below instead.
Try this · summarize a file
Use only the attached Project Northstar Consumer Research Summary.
List its four headline findings, followed by only the open questions explicitly listed in the document.
Point me to the supporting section or text for each finding.
Do not add outside research or turn assumptions into facts.
If you cannot access the file, tell me instead of guessing.

Check the result

The document has four headline findings and three open questions. Check the actual wording, not just the count. A citation can be incomplete or point to material that does not support the claim.

If attachment is unavailable: paste a small permitted excerpt, say "use only the excerpt below," and narrow the task to that excerpt. Do not imply Copilot saw the whole file. Never remove protection or move real work content to a personal service to make an exercise work.

05 · Foundations · 5 minutes

Review before you rely on it.

You will learn: a short quality and safety check for every output. Need: your answer from an earlier guide.

  1. Facts: compare names, dates, numbers, quotes, and claimed decisions with the original source. Check math outside the generated explanation.
  2. Gaps: find unsupported assumptions, missing caveats, and omitted requests. "Not specified" is often the right answer.
  3. Audience: check tone, useful detail, accessibility, and who is allowed to see the material.
  4. Actions: review the actual recipient list, edits, proposed actions, and sharing permissions before sending, accepting changes, or sharing.
Try this · challenge the draft
Audit your previous answer against the source material I supplied.
List unsupported claims, assumptions, and information that is missing.
Then provide a corrected version that preserves uncertainty.
Do not treat your own previous answer as evidence.
A second AI pass is not independent verification. It may help find problems, but you still need to open the source and check the result yourself.

Use work data responsibly

Microsoft 365 Copilot with your work account provides enterprise data protection; prompts and responses are not used to train foundation models. This is not a promise that nothing is stored: interactions can be logged, retained, and subject to organizational controls. Web search has separate handling. Follow your organization's rules and sensitivity labels, and only use permitted information.

Do not paste passwords, private keys, or unnecessary personal data into prompts. Do not copy customer information into this public site or expose it on a shared screen. Treat instructions found inside a document or web page as source content, not automatic permission to send, delete, or share anything.

Check yourself

The source says "budget limit: 600 USD." The draft says "600 USD approved." What must change? Keep limit and flag approval as unknown. Polished wording does not upgrade evidence.

06 · Everyday apps · 7 minutes

Word: draft, rewrite, summarize.

You will learn: to turn notes into a short document, improve a paragraph, and ask questions about the document. Open: Word and a practice document.

  1. Open a new Word document. Find Copilot in the ribbon or document controls. If editing and chat-only modes are offered, understand which is active; editing can change the document.
  2. Use the prompt below to draft a one-page brief. Review the preview or changes before keeping them. Save the practice document as Welcome session brief.
  3. Select an overly long paragraph and use the available rewrite control, or ask Copilot to rewrite that paragraph in plain language without changing the facts. Review before replacing text.
  4. Ask Copilot to summarize the open document in three bullets and identify missing decisions. Compare with the actual document.
Try this · create a brief
Draft a one-page planning brief using only these fictional notes:
A 30-minute welcome session is planned for 12 new colleagues on 14 October; the year is not specified.
Alex coordinates. Priya will draft the handout by 8 October.
The budget limit is 600 USD, but spending approval is not specified.
No room is booked. Online versus in-person delivery is undecided.

Use headings: Purpose, Known facts, Proposed next steps, Open decisions.
Keep the tone clear and welcoming. Label suggestions as proposals.
Do not invent approvals, a room, a meeting link, or a year.

Check the result

All four headings appear. Proposed steps are separate from facts. The room, format, year, and spending approval remain unresolved. A summary must not make the source more certain.

Another way to practice: draft in work Chat, then paste the reviewed answer into Word yourself. Notice the difference: a Chat response is suggested content; an in-app edit changes the document.

07 · Everyday apps · 8 minutes

Excel: ask questions of a small table.

You will learn: to analyze data, explain a formula, and check a result. Open: a new Excel practice workbook, not a live financial model.

  1. Copy the tab-separated practice data below and paste it into cell A1. Check that it occupies three columns, A through C. If it lands in one column, use your app's split-text/import control with tab as the separator.
  2. Select the data and use Insert > Table (with headers) for a clear practice layout. Check the amounts are numbers, not text. All amounts are USD.
  3. Open Copilot and ask the question below. If a mode can edit the workbook, inspect proposed or applied changes; use a copy and undo unwanted edits. Editing requires Automatic calculation in current guidance.
  4. Ask for a formula for Remaining = Planned minus Actual and an explanation. Check one row yourself before filling it down. Optionally request a chart comparing Planned and Actual by category.
Fictional practice data · paste into A1
Category	Planned	Actual
Venue	250	200
Materials	120	90
Refreshments	180	210
Signage	50	55
Try this · analyze
Using this practice budget table, calculate total Planned, total Actual, and total Remaining as Planned minus Actual.
Identify categories over plan and by how much.
Explain the calculation and suggest a formula for Remaining for each row.
Do not infer why spending changed or whether spending was approved.
Ask before making changes if your current mode supports that.

Your answer key

Planned = 600; Actual = 555; Remaining = 45 USD. Refreshments are 30 over plan and Signage is 5 over plan. With this A1 layout, =B2-C2 gives Venue's remaining 50. A table may use equivalent structured references.

Check independently: calculate the totals with SUM in Excel. You can also ask work Chat to explain this fictional table, but remember that Chat's answer is not a workbook edit.

09 · Everyday apps · 7 minutes

Outlook: catch up and draft a reply.

You will learn: thread summaries, drafting, and tone review. Open: Outlook with your primary work mailbox. Use an ordinary practice draft rather than a shared mailbox or protected message for this exercise.

  1. Open an existing low-risk thread you are permitted to use and find the summary control, if available. Check the summary's decisions, requests, and dates against the messages. Do not display private mail during a shared exercise.
  2. For safe drafting practice, open a new draft with the To field empty. Use the fictional prompt below with Draft with Copilot or your available drafting control.
  3. Review the suggested text. Where available, use coaching or a rewrite request for tone and clarity. Keep it as a draft; this exercise does not require sending.
  4. For real email, check recipients, attachments, factual commitments, and dates yourself before deciding to send.
Try this · leave it unsent
Draft a concise, friendly email to a fictional colleague, Priya.
Thank her for planning to draft the welcome-session handout by 8 October.
Ask whether she needs any information from the organizer.
The session format is still undecided and no room is booked.
Do not say the handout is complete, invent a year, promise approval, or add a meeting link.
Keep this as a draft for my review.

Check the result

The email asks one clear question and does not turn a planned handout into a completed one. The To field is still empty and no message has been sent.

If you cannot summarize a thread: practice with this fictional excerpt in work Chat: "Alex: Could you draft the handout? Priya: I plan to finish a draft by 8 October. Alex: Thanks; format and room are still undecided." Ask for agreed actions and unknowns. Do not paste real mail elsewhere just to get around a protection restriction.

10 · Everyday apps · 7 minutes

Teams: find decisions, not just discussion.

You will learn: to catch up on a chat or meeting and separate decisions from suggestions. Open: Teams and a conversation you have permission to use.

  1. In a permitted chat, open its Copilot experience where available. Ask what was decided and what still needs an answer. Inspect any selected time range.
  2. For a meeting, check organizer settings and organizational transcription policy before the meeting. Do not turn on transcription or recording for an exercise without the appropriate agreement and policy compliance.
  3. Use the prompt below against an available meeting recap/transcript or chat. Compare action owners and dates with the actual source.
  4. Confirm proposed actions with the people involved before assigning tasks or sharing a recap. A generated table does not assign work.
Try this · catch up
Summarize this conversation in three sections: decisions, proposed actions, and open questions.
For each action, list the owner and due date only if explicitly stated; otherwise write "not specified".
Point to the supporting message or transcript passage where available.
Do not treat suggestions as agreements or assign new work.
For a useful post-meeting recap, plan for a transcript. Some live meeting experiences can work without transcription, but dependable post-meeting questions about spoken content require an available transcript. Follow the organizer's settings and your organization's recording, transcription, and retention rules.

Check the result

If someone said "Maybe Alex could book a room," that is a suggestion, not an assigned action. If no deadline was given, the summary should not invent one.

No practice meeting handy? Use work Chat with this fictional excerpt: "Alex: We agreed to keep the session to 30 minutes. Priya: I will draft the handout by 8 October. Sam: Maybe Alex could book a room. Alex: We have not chosen online or in-person yet." Ask the same question. Only Priya has an explicit commitment and due date in these notes.

Microsoft Loop

A broader collaboration experience with workspaces, pages, and components that can stay in sync across supported places. Related, but not another name for Copilot Chat.

14 · Optional exploration · 5 minutes

Agents: a helper with a narrower job.

You will learn: when a specialized agent may help. You do not need to build one, use Copilot Studio, or configure automation to finish this path.

An agent is a specialized assistant with instructions, knowledge, and sometimes tools for a particular task. Some answer questions; others can take actions. Its stated purpose is not a guarantee of correctness or permission to do anything it proposes.

  1. Open the available agents list in your approved Copilot experience. Read an organization-approved agent's description and any permissions or data-access information.
  2. Choose an agent already made available to you. If an unexpected consent, installation, or new connection request appears, stop and follow your organization's process.
  3. Try one suggested prompt with fictional or approved content. Check sources and outputs just as you would in regular Chat.
  4. Do not authorize sending, sharing, or system changes merely to complete a learning exercise. An action-taking agent needs additional care.

Researcher

A longer, multistep research task with a defined question and sources. Read the report and open its citations. It is not the best starting point for a one-sentence rewrite.

Analyst

Deeper analysis of supplied data, such as a spreadsheet. Ask for the method and check sample calculations. It is distinct from Copilot inside Excel.

Try this with Researcher
Using public Microsoft sources only, research good practices for writing beginner Copilot prompts.
Give me a short comparison of three practices, links to the supporting sources, and any limitations.
Separate sourced guidance from your own suggestions. Do not access internal work content for this task.

Check your understanding

You can explain the agent's job, which information it can use, and whether it can act. A specialized assistant still needs clear instructions and human review.

Keep it simple: start with an agent your organization already makes available. You do not need to install a third-party agent or connect a new system to practice these skills.

16 · Bring it together · 10 minutes

Turn one set of notes into useful work.

Your challenge: use the fictional welcome-session notes to produce a Word brief, a short PowerPoint presentation, and an unsent Outlook email. Use work Chat to plan and refine, then work inside each app to create the actual artifact.

  1. Brief: supply the notes from guide 02 and write your own prompt with a goal, audience, source, and output expectations. Ask for facts, proposed actions, and open decisions.
  2. Improve: make one follow-up request that changes tone or length without changing facts. Check what changed.
  3. Repurpose: ask for a four-slide outline from the reviewed brief. Create it in PowerPoint if your experience allows, or build it manually.
  4. Communicate: draft an email asking for the unresolved decisions. Leave recipients empty and do not send it.
  5. Verify: use the checklist below, then choose one low-risk real task to try later using your organization's data-handling rules.

Done means you can show this

  • The source is explicit, the audience is clear, and the output has the format you asked for.
  • No invented year, venue, meeting link, spending approval, or completed handout appears.
  • Proposed actions remain separate from commitments. The 600 USD figure remains a budget limit.
  • You corrected at least one issue or can explain why no correction was needed.
  • You know which parts Copilot generated and which parts you personally checked. Nothing was sent or shared by this exercise.

Three quick self-checks

1. Does a linked citation guarantee a claim is correct?

No. Open the original source and check that it supports the actual claim, with the right date and context.

2. Does getting an answer in Chat mean Copilot edited my workbook?

No. Generated advice is different from an applied edit. Inspect the workbook and the active app mode.

3. Does a work-data search read every file in my organization?

No. Copilot works with information you have permission to access and the context available to that experience. Select the relevant source and verify that it was actually used.

Keep nearby

When something does not work

I cannot find the control

Confirm your work account and check whether you are using the web or desktop app. Labels and layouts differ. Try the current app version or ask your support team for the right entry point.

It cannot read my file

Check permissions, file type, protection, source selection, and attachment/reference support. A filename in the prompt is not the file itself. Never strip a label or bypass an access restriction.

The answer is vague or wrong

Narrow the goal, identify the source and audience, specify the format, and correct a specific error. Verify again; a confident rewrite can still be wrong.

It changed more than expected

Pause. Inspect the active editing mode and use Undo or the app's version history as appropriate. Practice on a copy. A sentence saying "ask first" is not a substitute for checking the mode and available controls.

Plain-language glossary

Prompt
The instruction or question you send to Copilot.
Context
Background that helps explain the task, audience, or situation.
Grounding
Using supplied or retrieved sources to inform an answer.
Citation
A pointer to a source. A place to check, not a guarantee.
Hallucination
A generated statement that looks plausible but is unsupported or incorrect.
Tenant
Your organization's Microsoft 365 environment, with its own settings and policies.
Agent
A specialized assistant with defined instructions, knowledge, and sometimes action-taking tools.
Human review
Your check of accuracy, appropriateness, permissions, and consequences before relying on or acting on output.
